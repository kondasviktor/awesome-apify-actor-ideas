# Security

## Reporting secrets

If you find an API key, token, or credential in this repository:

1. **Do not open a public issue containing the secret**
2. Email **hello@vibecoderslife.com** with subject `Awesome Apify Actor Ideas security`
3. We will rotate credentials and scrub history as needed

## Scope

This repository is documentation and idea teasers only. It does not run scrapers or store API keys.

## Maintainer incident response

1. Revoke the exposed key at the provider
2. Remove the secret from git history if committed
3. Note the incident privately (without the secret)

Solo-maintained, best-effort response via email.
