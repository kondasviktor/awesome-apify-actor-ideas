# Contributing

Thanks for helping Awesome Apify Actor Ideas stay useful for vibe coders.

## Ways to contribute

- Propose a new **public-data** Actor idea (open an issue with: title, category, one-line wedge)
- Suggest a clearer wedge wording for an existing teaser row
- Fix typos or broken links in the README

## Rules

1. **No secrets** in issues or PRs
2. Ideas must target **public pages / public registers** only — no login walls, paywalls, or unauthorized sources
3. Keep teaser rows short: title + category + wedge (no fake revenue claims)
4. Do not paste the proprietary Playbook 100-idea scoring spreadsheet into PRs
5. Code and list text contributions: MIT (see LICENSE)
